# CodeBag 🧰

**CodeBag** is a powerful, lightweight desktop application built with C++ and Qt designed for developers to store, organize, and quickly retrieve reusable code snippets. Instead of reinventing the wheel or searching through old projects, CodeBag keeps your essential code blocks just a click away.

## ✨ Features

- **Snippet Management:** Easily save, edit, and delete your frequently used code snippets.
- **Categorization & Tagging:** Organize your code by language, framework, or project for instant retrieval.
- **Fast Search:** Quickly find the exact code block you need with a responsive search system.
- **Intuitive GUI:** A clean and user-friendly desktop interface powered by Qt.
- **Cross-Platform:** Built with C++ and Qt, making it capable of running smoothly across different operating systems.

## 🛠️ Tech Stack

- **Core Language:** C++
- **Framework:** Qt (Widgets/QML)
- **IDE Support:** Qt Creator / VS Code / Code::Blocks
